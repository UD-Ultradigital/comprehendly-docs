Identity

element.id is the stable bind key. field_name is what voice and submissions write. Do not match on labels.

Two surfaces

  • Generated — SDK renders a linear field list from forms.page.get.
  • Bound — you keep your widgets; the store patches them.

Get a tenant

  1. Sign up at app.comprehendly.nz/signup
  2. Publish a form. Settings → API → publishable key (pk_*).
  3. Allowlist the demo origin (http://localhost:4173 for JS, https://ios-demo.comprehendly.nz for Swift).

Spec files (OpenAPI, FieldStore, patch schema) ship in each SDK spec/ folder and in this site: sdk-api.md · openapi.yaml
