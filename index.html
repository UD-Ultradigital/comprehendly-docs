Comprehendly Forms SDK

Client libraries for the Forms integration API. Use them to list published forms, load a page definition, fill fields (UI or voice), and save a submission.

apiVersion 1. Method names are the same on every platform (idiomatic casing allowed: page.get ≡ pageGet).

What you integrate with

Piece Role
Publishable key (pk_test_ / pk_live_) Tenant credential. Exchanged for a short-lived token. Not a user JWT.
integration_exchange Key → access_token. Requires an allowlisted Origin.
integration_gateway RPC: catalog, page, voice, submissions, prepared sessions.
FieldStore In-memory field values for one fill. Voice and UI both write here.
