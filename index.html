Introduction

Comprehendly Forms is a developer-facing integration for loading published form pages, filling fields in a shared store, capturing voice input through the hosted bridge, and saving submissions back to the platform.

This guide covers the classic integration flow: exchange a publishable key, load a page definition, choose a surface, capture values, and save a submission.

What stays stable

Topic Rule
Field identity Bind host widgets with element.id. Voice and save use field_name. Never bind or save by label.
Surfaces Choose one surface per field: generated FormView or host-side bind. Do not overlay Comprehendly chrome on top of host controls.
Voice Voice stays on the hosted voice-bridge.html / forms fill embed. Forms embed v1.3 posts stepcare:fields_updated.
Origin allowlist Exchange requires an allowlisted Origin. Common defaults are http://localhost:4173 for the JS demo and https://ios-demo.comprehendly.nz for Swift.

Choose an integration path

Goal Guide
Render SDK-managed controls from a published page Render a form
Keep your existing DOM or native widgets Bind existing fields
Fill the same store from a microphone Fill with voice
Persist field values as a submission Save a submission
