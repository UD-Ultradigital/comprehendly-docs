Swift

Repo: github.com/UD-Ultradigital/comprehendly-sdk-swift. Product: ComprehendlyForms for iOS 16+ and macOS 13+.

Add the package

  1. Clone the repository locally.
  2. Xcode → Package Dependencies → add the local package.
  3. Link the ComprehendlyForms library to your app target.

Client setup

import ComprehendlyForms

let client = ComprehendlyClient(publishableKey: "pk_test_…")
client.origin = "https://ios-demo.comprehendly.nz"
try await client.exchange()

https://ios-demo.comprehendly.nz is the default Swift origin. Keep it allowlisted on the publishable key or replace both the client origin and the allowlist entry together.

Complete example

import ComprehendlyForms
import SwiftUI

let pageId = "00000000-0000-0000-0000-000000000000"
let client = ComprehendlyClient(publishableKey: "pk_test_…")
var firstName = ""

try await client.exchange()
_ = try await client.pageGet(pageId)

try client.store.bind(elementId: "el-first-name") { value in
  firstName = value as? String ?? ""
}

try await client.exchange()

let submission = try await client.submissionsSave(
  pageId: pageId,
  fieldValues: client.store.values()
)

print(submission.id)

Voice and save rules

Keep voice on the hosted WebView bridge. Bind host controls with element.id, then let client.store.values() produce the submission payload keyed by field_name. Render VoiceBridgeView(url: voiceURL, store: client.store) in your SwiftUI hierarchy once you have the bridge URL.
