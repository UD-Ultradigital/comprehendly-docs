Install and authenticate

You need a Forms tenant, at least one published form page, and a publishable API key.

1. Tenant and key

  1. Create an account at app.comprehendly.nz/signup.
  2. Author a form and publish it. Catalog and fill only see published pages.
  3. Settings → API → create a publishable key (pk_test_ or pk_live_).
  4. Set allowed origins to the exact origin your client sends (scheme + host + port, no path). Examples: http://localhost:4173 (JS demo), https://ios-demo.comprehendly.nz (Swift client default).

The browser never puts pk_* on an iframe URL. Exchange first, then pass the short-lived token.

2. Scopes

Minimum for catalog, page, fill, and save:

forms.schemas:read
forms.submissions:read
forms.submissions:write

forms.schemas:read is the catalog/page permission name. There is no schema-form API.

3. Exchange

POST https://api.stepcare.app/functions/v1/integration_exchange 

{
  "key": "pk_test_…",
  "audience": "stepcare-embed",
  "requested_scopes": [
    "forms.schemas:read",
    "forms.submissions:read",
    "forms.submissions:write"
  ]
}

Send the platform anon key as apikey and Authorization: Bearer (same as forms.js). Native clients must also send header Origin matching the key allowlist. Browsers set Origin themselves — do not override it.

Response includes access_token, expires_in (seconds), tenant_id, scopes.

4. Gateway

All operations go to POST …/functions/v1/integration_gateway 

{
  "access_token": "scist_…",
  "operation": "forms.catalog.list",
  "params": {}
}

Success envelope: { "data": …, "request_id": "uuid" }. SDKs return data.

Install the client

JavaScript

git clone https://github.com/UD-Ultradigital/comprehendly-sdk-js.git
cd comprehendly-sdk-js
cp demo/env.example.js demo/env.js   # set publishableKey
python3 -m http.server 4173 --directory demo

From an app, import Comprehendly from src/index.js (npm package name @comprehendly/forms, not on the registry yet).

Swift

git clone https://github.com/UD-Ultradigital/comprehendly-sdk-swift.git
# Xcode → Add Package Dependency → local path, product ComprehendlyForms

Demo wiring: Examples/Demo/ComprehendlyDemoApp.swift.

CLI (smoke test)

From the private core checkout, if you have it:

node cli/comprehendly.mjs init
node cli/comprehendly.mjs doctor

There is no public “create tenant from CLI” API. Signup is the browser flow above.
