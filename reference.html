API reference

Human-readable contract: spec/sdk-api.md · Machine-readable contract: spec/openapi.yaml.

Exchange and gateway

Endpoint Purpose Notes
POST /integration_exchange Exchange a publishable key for a short-lived token Requires an allowlisted Origin.
POST /integration_gateway Invoke Forms operations Requests include access_token, operation, and params.

SDK methods

Method Gateway operation Notes
exchange() integration_exchange Uses the configured publishable key and origin.
catalog.list(parentId?) forms.catalog.list Lists folders and published form pages.
page.get(pageId) forms.page.get Loads the current page schema and refreshes store bindings.
session.start({ pageId, mode }) forms.voice.start Use the returned token with the hosted voice bridge.
submissions.save(...) forms.submissions.save Payload values are keyed by field_name.
store.bind / store.set / store.values Local only Bind with element.id, save with field_name.

Additional gateway operations

Operation Purpose
forms.submissions.list / forms.submissions.get Read previously saved submissions.
session.prepare / session.get / session.complete Manage prepared sessions and related fill context.
