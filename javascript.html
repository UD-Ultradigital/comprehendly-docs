JavaScript

Repo: comprehendly-sdk-js. Entry: src/index.js (export class Comprehendly).

Constructor

new Comprehendly({
  publishableKey,      // required
  origin,              // set Origin header only in non-browser runtimes
  functionsUrl,        // default production Functions URL
  anonKey              // default platform anon key
})

client.store is created with the client. page.get calls store.loadPage.

Demo

git clone https://github.com/UD-Ultradigital/comprehendly-sdk-js.git
cd comprehendly-sdk-js
cp demo/env.example.js demo/env.js
# publishableKey, optional pageId
python3 -m http.server 4173 --directory demo

Allowlist http://localhost:4173. The page shows generated controls and host-bound inputs on the same store.

CDN widget

https://sdk.comprehendly.nz/embed/v1/forms.js mounts iframes (StepCareForms.init). Use it when you want the hosted fill UI, not FieldStore.
