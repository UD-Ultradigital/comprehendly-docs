JavaScript

Repo: github.com/UD-Ultradigital/comprehendly-sdk-js. The client exposes Comprehendly, a shared store, and helpers for voice bridge mounting.

Constructor

new Comprehendly({
  publishableKey,   // required
  origin,           // only for non-browser runtimes
  functionsUrl,     // defaults to production Functions URL
  anonKey           // defaults to the platform anon key
})

Browsers should not override origin. For the demo flow, allowlist http://localhost:4173 on the publishable key.

Complete example

import { Comprehendly, mountVoiceBridge } from './src/index.js'

const pageId = '00000000-0000-0000-0000-000000000000'
const client = new Comprehendly({
  publishableKey: 'pk_test_…'
})

await client.exchange()
await client.page.get(pageId)

client.store.bind({ elementId: 'el-first-name' }, (value) => {
  document.querySelector('#first-name').value = value ?? ''
})

document.querySelector('#first-name').addEventListener('input', (event) => {
  client.store.set({
    elementId: 'el-first-name',
    value: event.target.value,
    source: 'bind'
  })
})

mountVoiceBridge('#voice', {
  token: client.accessToken,
  pageId,
  mode: 'assistant',
  store: client.store
})

document.querySelector('#save').addEventListener('click', async () => {
  const submission = await client.submissions.save({
    pageId,
    fieldValues: client.store.values()
  })

  console.log('Saved submission', submission.id)
})

Exchange tokens are short-lived. If a user spends a while filling the form, exchange again before save instead of assuming the original token is still valid.

Generated vs bound surfaces

Use generated UI when you need a quick linear form. Use bind when you already own the DOM. Do not draw both for the same field. Bind through element.id; save through the store's field_name-keyed values.

Demo

git clone https://github.com/UD-Ultradigital/comprehendly-sdk-js.git
cd comprehendly-sdk-js
cp demo/env.example.js demo/env.js
# set publishableKey and optional pageId
python3 -m http.server 4173 --directory demo

The hosted voice bridge stays on /voice-bridge.html, while the demo origin remains http://localhost:4173 for exchange and gateway calls.
