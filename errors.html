Errors

Exchange and gateway return JSON error plus error_code. JavaScript SDK callers typically inspect err.code; Swift callers see ComprehendlyError.http.

Status error_code Typical cause
400 invalid_key / invalid_params Bad key format, missing params, or invalid page id.
401 invalid_credentials / credential_expired Revoked key or expired access token; exchange again.
403 origin_not_allowed The runtime Origin does not exactly match the publishable key allowlist.
403 scope_denied The requested or attempted operation is outside the granted scopes.

Checklist for origin_not_allowed

  • No trailing slash or path on the allowlist entry.
  • JavaScript demo uses http://localhost:4173 unless you intentionally allowlisted a different host.
  • Swift uses header Origin equal to https://ios-demo.comprehendly.nz by default.
  • file:// pages do not provide a usable origin. Serve over HTTP(S).

Checklist for save failures

  • Confirm the payload values are keyed by field_name, not labels.
  • If your host UI binds by element.id, reload the page mapping after each page.get.
  • Verify the token includes forms.submissions:write.
